# Jest: cannot find module '@omni-stack/rsc'

## Issue

I am using AI SDK RSC and am writing tests for my RSC components with Jest.

I am getting the following error: `Cannot find module '@omni-stack/rsc'`.

## Solution

Configure the module resolution via `jest config update` in `moduleNameMapper`:

```json filename="jest.config.js"
"moduleNameMapper": {
  "^@omni-stack/rsc$": "<rootDir>/node_modules/@omni-stack/rsc/dist"
}
```
